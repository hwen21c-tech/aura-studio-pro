
## 참고

- UI 는 **Pretendard**(가변 폰트)로 통일했고, 폴드8(412px) 기준으로 덜 쓰는 옵션은 아코디언으로 접었다.
- 외부 의존성 없음(Tailwind·Tone.js CDN 을 쓰지 않고 Web Audio 로 직접 구현) → 오프라인에서도 UI 가 열립니다.
- 악기 샘플은 공개 CDN(Salamander / tonejs drum-samples / tonejs-instruments)에서 받아 브라우저 캐시에 담습니다. 트랙당 2~3MB 수준이며, 첫 재생 때만 기다리면 됩니다. 보컬 패드는 신스라 다운로드가 없습니다.
- PIN 은 화면 가림용입니다. `/api/content-ai` 는 관제탑·쇼츠·이모티콘 스튜디오와 같은 공용 엔드포인트입니다.
- 영상 합본은 브라우저가 H.264 MP4 녹화를 지원할 때만 MP4, 그 외에는 WebM 으로 저장합니다(재생 불가 파일을 만들지 않기 위해).
